# Gym Session Tracker & AI Workout Planner                              
                                                                          
  > Live at **[gymrudy.com](https://gymrudy.com)** · Built and deployed   
  solo from scratch                                                       
                                                                          
  A full-stack web app for tracking workouts, generating AI-powered plans,
   and sharing fitness routines — built because every tracker I tried
  locked features behind a paywall.                                       
                                                            
  > **Note:** This repo is a public showcase. The full source code is     
  private to protect business logic and user data.
                                                                          
  ---                                                       

  ## Why I Built This

  I've always been into fitness and wanted a simple way to track my 
  workouts over time. Every app I tried had paywalls on the features that 
  mattered. With some foundation in web development and hands-on experience
  with modern AI tooling, I decided to build my own.
  
  What started as a personal tool grew into something others can use to 
  browse my workouts, generate their own plans, check out my supplement
  stack, or book a session with me.                                       
                                                            
  ---

  ## Features

  - **Workout logging** — track sessions over time with a personal history
  - **AI workout generation** — tell it your goal, time constraint, and
  available equipment and get a full plan (powered by Groq / Llama 3.3)   
  - **Public workout browsing** — visitors can explore my logged sessions
  without an account                                                      
  - **Supplement stack** — view the supplements I take and why
  - **Personal session booking** — book a workout with me directly through
   the app                                                  
  - **User authentication** — email/password sign-up with email           
  verification                                                            
  - **Stripe integration** — checkout flow for session booking and
  payments                                                                
  - **Transactional email** — automated emails via Resend for
  verification, receipts, and confirmations                               
  - **Admin dashboard** — protected view for managing users, sessions, and
   bookings
