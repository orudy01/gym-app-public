# Gym Session Booking SaaS

> Live at **[gymrudy.com](https://gymrudy.com)** · Production app with real paying users

A full-stack SaaS platform for gym session logging and booking — built and deployed solo from scratch.

> **Note:** This repo is a public showcase. The full source code is private to protect business logic and user data.

---

## Features

- **Public workout browsing** — visitors can explore available sessions without an account
- **User authentication** — email/password sign-up with email verification required before access
- **Payment gating** — verified users must complete Stripe checkout to unlock paid features
- **Stripe integration** — full checkout flow for session booking and subscription payments
- **Transactional email** — automated emails via Resend for verification, receipts, and booking confirmations
- **Admin dashboard** — protected admin-only view for managing users, sessions, and bookings
- **Production deployment** — live on custom domain with ongoing maintenance and real user traffic

---
